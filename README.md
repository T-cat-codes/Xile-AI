# Xile AI

Xile AI is a desktop AI assistant application built with Electron and plain JavaScript. It runs AI models using Ollama on your local machine.

## Features

- Local AI processing with Ollama
- Chat interface with message history
- File editing capabilities
- Screen capture and interaction tools
- TV casting support
- Web search capabilities
- Customizable settings

## Project Structure

- `app/` - Core application logic
- `ui/` - User interface files (CSS, JavaScript)
- `scripts/` - Setup and utility scripts
- `icon.png` - Application icon
- `XILE.md` - Documentation

## Requirements

- Node.js
- Ollama
- Windows 10 or later

## Installation

1. Run `Setup Xile AI.cmd`
2. Install required models with Ollama

## Usage

Launch the application and start chatting with your AI assistant.
